# RadiusOne 2.31.0

Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

- **One count of weak ONUs everywhere:** the menu, the Overview, the OLT page, its Weak signal filter and its graph now
  count the same ONUs: online, with a weak signal at the ONU or at the OLT. An offline ONU's last reading is old, so it
  no longer counts. Before, the menu and the OLT page could show different numbers.
- **Your company logo keeps its shape** on the dark menu and the sign-in screen: the white tile is as wide as the logo
  needs, and the logo is shown larger.

## What the update changes on the server

Nothing besides the code. Customers stay connected.
