# RadiusOne 2.16.3

The ONU's page stays where you are and stops waiting on the OLT. Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

- **An action no longer rebuilds the page.** After Save, Push to the ONU, Turn off, Reboot or a rename, the page used to
  start over: it lost what it had read, showed "Asking the OLT" for several seconds and jumped towards the top. It now
  stays on the tab and at the place you were, keeps what it shows, and brings it up to date in the background.
- **The page opens with the last read at once.** The portal keeps each ONU's last read for a week. The page shows it
  straight away, says how old it is, and asks the OLT again by itself.
- **Tabs open at once.** Ports, Speed profiles, Configure and Running config no longer ask the OLT when you open them:
  everything comes with the page's one read, and Configure's choices (VLANs, profiles, speeds) are fetched before you
  open the tab. Going to another tab and back does not load anything again.
- **The Configure tab needs no login of its own to the OLT** to see what the ONU has set.
- **A failed read no longer empties the page.** It keeps the read before and says that the last one failed.
- **Traffic** at the top of the page is the average of the last 5 minutes, from the regular reads. In 2.16.2 it showed a dash.

## What the update changes on the server

Nothing besides the code. Customers stay connected.
