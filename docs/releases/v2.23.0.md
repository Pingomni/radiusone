# RadiusOne 2.23.0

A new Overview page. Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

- **The title says how the network is,** in one sentence: "Everything is working.", or the most urgent problems, such as
  "One router is not answering and 5 ONUs have a weak signal."
- **Needs attention:** routers not answering, OLTs that cannot be read, ONUs with a weak signal (by OLT, with the port
  most of them share), routers waiting for a FreeRADIUS restart and overdue invoices. Each has a button to the page
  that fixes it.
- **Routers:** status, CPU, live sessions and uptime for each NAS.
- **Expiring this week:** the clients whose service ends in the next 7 days, soonest first.
- **Key figures** in one strip; top users and failed logins stay.

## What the update changes on the server

Nothing besides the code. Customers stay connected.
