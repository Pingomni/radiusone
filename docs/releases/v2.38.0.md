# RadiusOne 2.38.0

Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

- **Devices** (new, in the menu under Network): routers and OLTs in one list with their state. Tabs for All,
  Routers, OLTs and **Needs a look**; each row shows the address, state, what is in use (clients online or ONUs,
  opening Sessions or ONUs for that device), its readings and what is wrong with it, from the same checks as
  Monitoring. *New router* and *New OLT* are on the page.
- **OLT changelog** (button on the OLTs page): what changed on every OLT in one list, with an OLT filter next to the
  existing search, kind, source and person filters.

## What the update changes on the server

Nothing besides the code. Customers stay connected.
