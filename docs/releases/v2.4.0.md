# RadiusOne 2.4.0

A firewall in the portal, under *Settings → Firewall*. Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

- **Manage this server's firewall from the portal.** It uses nftables and stays **off** until you turn it on, so
  updating changes no firewall rules.
- **It starts from a template you can change:** the portal (TCP 80 and 443) from anywhere, RADIUS (UDP 1812 and 1813)
  from your routers, and SSH only from your management networks. Everything else coming in is dropped.
- **Turn it on and off whenever you want.** Turning it off keeps your rules. You can also add, edit, reorder or pause
  rules, block an address for a limited time, and restore the template.
- **RADIUS follows your routers.** The "routers" source uses the addresses under NAS and updates itself within a
  minute. A router listed by name instead of an address isn't included, and the page warns you about it.
- **Protection against lockouts.** If your browser can't reach the server within a minute of a change, the previous
  rules come back. If you're still locked out, run `sudo radiusone-firewall off` from the server's console.
- **Fresh installs work again.** The installer gave the migration user its database rights too late, so a new install
  stopped with "Access denied".
- **The repository moved** to `Pingomni/radiusone`. Update checks and links use the new address; the old one redirects.

## Before you turn the firewall on

- Add your routers under *NAS*, or RADIUS is blocked for everyone.
- Check that the management networks include an address you can always reach SSH from, such as a fixed address or a
  VPN network.
- If `ufw` is active, both firewalls apply, so a port has to be open in both.
- Keep console access to the server the first time you turn it on.

## Installing

- **Servers on 2.3.0 to 2.3.4:** *Settings → Overview → Software update* → **Install RadiusOne 2.4.0**, or
  `sudo radiusone-update`.
- **Servers on 2.2:** install this version with the update button, then **Finish moving to RadiusOne**.
- **New servers:** see INSTALL.md.
