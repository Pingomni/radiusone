# RadiusOne 2.22.0

Shared parts of the portal's new look. Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

- **Key figures in one strip of numbers** on the dashboard, billing, monitoring, reports, logs, online payments and
  network operations pages. A number that needs a look is amber or red.
- **The fibre signal scale:** one red, amber and green bar with a marker, on the OLT's ONU list, the ONU page and the
  client's ONU tab. The zones follow each OLT's own weak and very weak levels.

## What the update changes on the server

Nothing besides the code. Customers stay connected.
