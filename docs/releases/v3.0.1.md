# RadiusOne 3.0.1

- My servers: when the server checks in with your PingOmni account (twice a day, once registered), it now says which RadiusOne version it runs and how many clients it holds. Servers in [account.pingomni.com](https://account.pingomni.com/servers) lists each of your servers with its version, whether an update is waiting, its clients against the licence's limit, and when it last checked in; you can name each one there.
