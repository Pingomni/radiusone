# RadiusOne 2.37.0

Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

Two more lists that span every device.

- **Sessions** (new, in the menu under Operations): every open session on every router in one list. Tabs for Online,
  No recent update and All open; search by username, name, IP or MAC; a router filter when there is more than one.
  Each row shows the client, router, IP and MAC, service, start and duration, and data. **Disconnect** is on the row
  for people who may disconnect, and returns to this list.
- **PON ports** (new, under Network): the PON ports of every OLT in one list. Tabs for All, In use and
  **Needs a look** (rogue ONU, all ONUs offline, autofind off, full, weak average signal, turned off); an OLT filter;
  ONUs online, offline and free places, average signal, transmit power and module temperature.
- A port's numbers open the list of all ONUs filtered to that port; the filter shows as a chip that can be removed.

## What the update changes on the server

Nothing besides the code. Customers stay connected.
