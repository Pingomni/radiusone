# RadiusOne 2.33.0

Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

- **Max ONUs per PON port** (as in SmartOLT): a new setting in each OLT's settings, *PON ports*, from 1 to 128
  (default 128, all a Huawei GPON port takes). Adding an ONU on a port that already has that many is refused before
  anything is sent to the OLT. ONUs already on a port stay; nothing changes on the OLT.
- The OLT's **Ports** tab shows the free places on each PON port, and "Full" when there are none.

## What the update changes on the server

Database migration `042_olt_max_onus.sql` adds one column to `olts` (applied by the update). Customers stay
connected.
