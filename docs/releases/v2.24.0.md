# RadiusOne 2.24.0

A new client list. Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

- **Views with counts:** All, Online, Expiring this week, Expired, Suspended and Disabled (and Archived when there are
  any). Expiring this week lists the soonest first.
- **Rows that read at a glance:** name and username, connection (a dot and a word) with the account state beside it
  when it is not active, service, IP and router, expiry date with "in 2 days" or "5 days ago", traffic and balance.
- **A side panel:** click a row to see the subscription, balance, live session and fibre signal beside the list, with
  buttons to the profile and diagnostics. Esc closes it.
- **The search also finds IP and MAC addresses,** as before; plan and router filters sit beside it.

## What the update changes on the server

Nothing besides the code. Customers stay connected.
