# RadiusOne 2.12.0

PON port and card actions, a traffic graph for every OLT port, and a read-only command line. Update with
*Settings → Overview → Software update*, or `sudo radiusone-update`.

- **PON port actions.** On an OLT's **Ports** tab, **More** on a PON port has **Turn autofind on / off**, **Restart all
  ONUs**, and **Turn port off / on**.
- **Restart a card.** On the **Cards** tab. You type the card's name to confirm.
- **A traffic graph for every port.** **More → Traffic graph** on any uplink or PON port, over the range chosen under Graphs.
- **Command line (read only).** A new tab runs one `display` command on the OLT and shows the answer. Nothing but
  `display` commands is sent, so it cannot change the OLT.
- **History** also lists these actions and the commands run.

## What to know

- **The actions need Allow changes from the portal** turned on for the OLT, and the right to manage NAS devices. Turning a
  port off and restarting a card also need the right to delete. The graphs and the command line work with changes off.
- **The portal checks first.** A port action is only sent to a port the OLT itself lists, and a card is only restarted if the
  OLT still has that card in that slot. After autofind and port off / on, the portal reads the setting back from the OLT.
- **Restarting the active control card** moves the OLT to its standby card, or restarts the whole OLT if it has none.
- **A port's graph starts empty.** It fills from the second read after the update, one point a minute, kept for 8 days.
- **The command line can show the OLT's own passwords** (for example in its configuration), so only people who may manage
  NAS devices have it, and each command is written to the audit log.
- **Checked on a Huawei MA5800-X7** (V100R018C00): the graphs and the command line were run against a real OLT. The port and
  card actions were tested on a simulator. Try your first one on a port or card you can afford to lose for a minute.

## What the update changes on the server

One new table (port traffic history). No OLT is changed by the update. Customers stay connected.
