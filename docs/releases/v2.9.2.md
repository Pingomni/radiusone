# RadiusOne 2.9.2

A fix for 2.9.0. Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

- **The online payments check stopped with "Unknown lifecycle job".** The job that checks open pay page payments every
  5 minutes, and ends contracts past their end date, was not registered, so a payment whose webhook was missed stayed
  waiting. It now runs, and shows under **Monitoring → Background jobs** as *Online payments*. A test runs the job itself.

## What the update changes on the server

Nothing besides the code. Customers stay connected.
