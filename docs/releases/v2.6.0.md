# RadiusOne 2.6.0

See your OLT and which client is on which ONU, under *OLT* in the menu. Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

- **OLT list and ONUs.** Add a Huawei MA5800-X7. Each ONU shows its port, serial number, description, status, signal at both
  ends, distance and why it last went offline.
- **Client mapping.** A client is linked when its session's MAC is behind exactly one ONU, or when an ONU's description matches
  its username. You can also link by serial number on the client's new **ONU** tab.

## What to know

- **Read-only.** The SNMP client can't send a change, and the telnet client can send only `enable`, `scroll`,
  `display mac-address all` and `quit`.
- **Only the Huawei MA5800-X7 for now.** The values and commands were built from public documentation and tested against a
  simulator, not yet against a real OLT, so check the first results against your OLT. An unexpected format shows as an error
  on the OLT's page and the last good list is kept.
- **This server must reach the OLT's management address,** on UDP 161 and, for telnet, TCP 23.
- **Telnet is optional and not encrypted.** Without it, clients aren't found from their MAC. Keep it on your management network
  and use a user with few rights.
- **A link is never replaced automatically.** *Client mapping* shows it when a session points to a different ONU.
- **Timing.** The ONU list is read every 5 minutes and the MAC table every 15.

## What the update changes on the server

Four new database tables and one scheduled job, which does nothing until you add an OLT. Customers stay connected.
