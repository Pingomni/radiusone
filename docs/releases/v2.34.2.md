# RadiusOne 2.34.2

Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

- **Fixed:** the app installed on a phone (Add to Home screen / Install app) still showed the old "R" icon. Its icons
  now show the RadiusOne Key, like the browser tab and the iPhone icon. A phone that already has the app keeps
  its old icon until the app is removed and installed again.

## What the update changes on the server

Nothing besides the code. Customers stay connected.
