# RadiusOne 2.30.0

The ONU page in the new look, same layout. Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

- **The ONU's name is the page title,** with where it is (ONU, port and OLT, linked) and its serial number under it.
- **The state as a dot and a word;** disconnections in the last 24 hours in amber words.
- **The two signal readings and the traffic in one strip,** with plain labels ("ONU receives", "OLT receives").
- **Ports, speed profiles and connections** show Up and Down as a dot and a word.
- **Shorter notices,** and the breadcrumb replaces the separate path above the page.
- The drawing of the ONU with its ports, the last 24 hours, the facts and the tabs stay as they were.

## What the update changes on the server

Nothing besides the code. Customers stay connected.
