# RadiusOne 2.16.1

A fix for the ONU's page. Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

- **The ONU's picture and status stayed as they were when the page opened.** The LAN port lights, the signal and the state
  only changed after pressing **Get status** or turning **Live** on. The page now asks the OLT again every 30 seconds by
  itself, and every 10 seconds with **Live** on.
- **Live stopped for good after the page had been in the background.** It now carries on as soon as you look at the page again.

## What to know

- **Nothing is asked while the page is in the background,** so an ONU page left open in another tab does not keep logging in
  to the OLT.

## What the update changes on the server

Nothing besides the code. Customers stay connected.
