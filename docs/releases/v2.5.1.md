# RadiusOne 2.5.1

Get back into the portal when you're locked out. Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

- **Reset a portal password from the terminal.** Run this on the server, using your login in place of `admin`:

  ```
  sudo radiusone-root-artisan radiusone:reset-password admin
  ```

  It asks for the new password twice without showing it, so the password stays out of your shell history. Leave the login
  out to list the logins.
- **Lost the authenticator phone too?** Add `--reset-2fa`. The next login then sets up a new authenticator app.

## What to know

- **The rules match the portal:** at least 10 characters, and different from the current password.
- **Open sessions for that login are logged out,** and any lockout from wrong authenticator codes ends. The login page's
  limit on wrong passwords still applies, so after too many attempts wait 15 minutes.
- **Each reset is in the audit log,** with the server user who ran it. The password never is.
- **A disabled login stays disabled.** The command warns you, and you enable it under *Settings → Users*.

## What the update changes on the server

Nothing beyond the new command. Customers stay connected.
