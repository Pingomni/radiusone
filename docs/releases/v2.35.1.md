# RadiusOne 2.35.1

Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

- **Fixed:** opening an OLT's ONUs with a filter (the Overview's ONUs online, ONUs offline and Weak signal figures,
  the OLTs table, the figures on the OLT page) showed the top of the page. It now goes to the ONU list.
- **Weak signal** is a tab of the ONU list, next to All, Online and Offline, so the filter shows as selected.
- Changing the filter or searching in the list keeps the place on the page.

## What the update changes on the server

Nothing besides the code. Customers stay connected.
