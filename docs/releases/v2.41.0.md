# RadiusOne 2.41.0

- ONU page: a new Status tab shows everything the OLT says about the ONU, as text, like SmartOLT's "Get status": optical status, ONU details, up and down history, WAN and LAN interfaces, MACs on the OLT from the ONU, and the devices online behind it (cable and Wi-Fi).
- A Copy button copies the whole report.
- It only reads from the OLT, so it works with changes turned off. It needs telnet turned on for the OLT.
- VoIP status is not included.
