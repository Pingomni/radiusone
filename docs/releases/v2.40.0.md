# RadiusOne 2.40.0

Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

- **Filters on the ONUs page**, as in SmartOLT: **OLT**, **Board**, **Port** (of the board chosen), **VLAN**,
  **ONU type**, **Profile** and **Client** (linked or not). Each offers only the values that exist; choosing one
  updates the list at once, and the tabs (All, Online, Offline, Weak signal) count what the filters leave.
  *Clear filters* removes them.
- **A wider search:** serial, name on the OLT, a **MAC** behind the ONU, and the linked client's username, name,
  **address**, **phone** or **IP**.
- SmartOLT's *Zone* and *Splitter* are labels kept in SmartOLT itself; the OLT has no such data, so they are not here.

## What the update changes on the server

Nothing besides the code. Customers stay connected.
