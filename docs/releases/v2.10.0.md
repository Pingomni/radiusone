# RadiusOne 2.10.0

Manage ONUs on the OLT from the portal: add a new ONU, restart it, turn it off and on, rename it and remove it. Update with
*Settings → Overview → Software update*, or `sudo radiusone-update`.

- **Off until you turn it on.** Each OLT has **Allow changes from the portal** under **Edit**. Until it is on, the portal only
  reads that OLT, as before.
- **New ONUs.** **OLT → New ONUs** lists the ONUs that are plugged in but not yet added. Choose one, check the profiles, VLAN and
  traffic tables, and press **Add this ONU**. The form starts from what most ONUs on the OLT use, then from what you used last.
  Router mode (the ONU gets its address by DHCP) and bridge mode are supported.
- **Add an ONU for a client.** A client's **ONU** tab has **Look on <OLT>**: the new ONU gets the client's name as its
  description, and is linked to the client once added.
- **An ONU's own page.** Click a serial number. **Right now** asks the OLT for the ONU's state, signal, temperature, software,
  its internet connection (address, gateway, DNS, VLAN) and its LAN ports. This works with changes off too.
- **Restart, turn off, turn on, rename, remove.** On the ONU's page. Removing also deletes the ONU's service ports and unlinks
  its client, and needs the right to delete.
- **A turned off ONU shows as "Turned off"** in the lists, also when it was turned off on the OLT itself.

## What to know

- **The right ONU, every time.** Before any change, the portal asks the OLT which serial number is at that position. If it is
  not the one you opened, nothing is sent.
- **Nothing half done.** If the OLT refuses a step while adding an ONU, the ONU is taken off again and you see the OLT's own
  error.
- **Every change is in the audit log,** with who made it and the exact commands sent.
- **The telnet user needs the right to configure** on the OLT once changes are on. With changes off, read rights are enough.
- **The OLT saves by itself.** The portal does not send `save`. A Huawei OLT saves changed settings on its own timer
  (`display autosave configuration`); check that yours has it on.
- **Use one system to add ONUs.** If SmartOLT or another system also adds ONUs to the same OLT, stop using it for that first.
- **Speed stays with RADIUS.** The traffic tables on the form are the OLT's own ceiling, not the customer's plan.
- **Not yet here:** Wi-Fi name and password, VoIP, IPTV, moving an ONU to another port, and ONU software updates.
- **Tested on a Huawei MA5800-X7** (V100R018C00). Reading was run against a real OLT. The change commands were checked against
  that OLT's command help and tested on a simulator. Try your first change on one ONU you can reach.

## Fixed

- **The MAC table read could fail or return nothing on some OLTs.** An OLT that prints a notice just after login (for example
  "The user password is set by other administrator") shifted every answer by one. The portal now waits for the OLT to finish.

## What the update changes on the server

Three new columns (two on OLTs, one on ONUs). No OLT is changed by the update. Customers stay connected.
