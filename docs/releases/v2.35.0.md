# RadiusOne 2.35.0

Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

The Overview shows clients and fibre together, and every number opens its list.

- **One strip of six figures**, each with an icon and each clickable:
  - **Clients online** (with active clients and today's data) → the online clients;
  - **Expired** (with disabled) → the expired clients;
  - **ONUs waiting** (new on the fibre, not added yet) → the page that adds them;
  - **ONUs online** (of all) → the online ONUs;
  - **ONUs offline**, split into power off, LOS and other → the offline ONUs;
  - **Weak signal**, split into warning and critical → the weak ONUs.
  Without an OLT the strip keeps its six client figures; Data today and Data this month now open Reports.
- **OLTs table:** one row per OLT with its state and the same counts, each a link, and **Add ONU**.
- **ONUs, last 24 hours:** the online / offline / weak graph, on the Overview.
- All of it refreshes on its own. "ONUs waiting" comes from the OLT's 15-minute reading.

## What the update changes on the server

Nothing besides the code. Customers stay connected.
