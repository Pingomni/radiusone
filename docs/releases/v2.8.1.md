# RadiusOne 2.8.1

The user guide moves to pingomni.com. Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

- **Documentation opens the guide on pingomni.com** ([pingomni.com/docs/radiusone](https://pingomni.com/docs/radiusone/)),
  in a new tab, for every operator (it was for superadmins only). The guide there is much longer: every page, field and
  button with examples, and every server command.
- **The setup guides** for Backblaze B2, Cloudflare R2 and Telegram open the matching part of it.
- The portal no longer carries its own copy. An old bookmark of `/docs` opens the new page.

## What the update changes on the server

Nothing: no database changes. Customers stay connected.
