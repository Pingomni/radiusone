# RadiusOne 2.20.0

The portal's new look, first part. Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

- **New colours:** a petrol teal for buttons and links, green only for what works, amber and red for what needs a look.
  Dark theme included.
- **New typefaces,** shipped with the portal: Instrument Sans, and Red Hat Mono for addresses and serial numbers.
- **Flatter controls:** buttons, fields, tags, tables and tabs with lighter weight and rounder corners.

Pages keep their layout; the frame, menu and overview follow in the next releases.

## What the update changes on the server

Nothing besides the code. Customers stay connected.
