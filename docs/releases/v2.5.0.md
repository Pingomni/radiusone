# RadiusOne 2.5.0

See why a router can't connect, under *NAS → your router → Diagnostics*. Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

- **Connection checklist.** Shows whether the NAS is on and loaded, FreeRADIUS is running and listening, the firewall
  lets the router through, and logins and accounting are arriving, with what to fix for each problem.
- **60-second packet test.** Press **Start** and try a login on the router. It says whether requests arrive, whether the
  server answers, and whether the shared secret is wrong.
- **Unknown routers.** The *NAS* list shows addresses that send RADIUS requests but aren't in your list, with **Add as
  NAS**. This is often a router behind NAT. Addresses you don't recognise may be internet scanners, so don't add those.
- **Recent errors in plain words,** including why logins were rejected.

## What to know

- **The wrong-secret check needs signed requests.** Accounting requests are always signed, but login requests only when
  they carry a Message-Authenticator. Without one, a wrong secret can look like a wrong password, and the page says so.
- **The packet test holds whole RADIUS packets,** including usernames. They stay in memory, readable only by root and the
  web server, and are deleted after 15 minutes. The shared secret is never shown.
- **Who can use it.** Anyone who can view a NAS can open the tab. Starting the packet test needs the right to manage NAS
  devices.

## What the update changes on the server

- **Login logging is switched on in FreeRADIUS,** without passwords. It starts at the next FreeRADIUS restart
  (*Monitoring → RADIUS server → Restart*). The update doesn't restart FreeRADIUS, so customers stay connected. Until
  then, the per-router login count is unavailable.
- **`tcpdump` is installed** if it's missing. The packet test needs it.
- **If the firewall is on, its rules reload once** within a minute, with one new line that logs dropped RADIUS requests.
  What's allowed doesn't change.

## Installing

- **Servers on 2.3.0 to 2.4.0:** *Settings → Overview → Software update* → **Install RadiusOne 2.5.0**, or
  `sudo radiusone-update`.
- **Servers on 2.2:** install this version with the update button, then **Finish moving to RadiusOne**.
- **New servers:** see INSTALL.md.
