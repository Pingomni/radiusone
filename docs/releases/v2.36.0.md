# RadiusOne 2.36.0

Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

Built for several OLTs and routers: find an ONU without first choosing its OLT.

- **ONUs** (new, in the menu under Network): every ONU on every OLT in one list. Tabs for All, Online, Offline,
  Weak signal and **Waiting** (new on the fibre, not added yet, with an Add button); search by name, serial or client;
  an OLT filter when there is more than one. Each row shows its OLT and port.
- **From one ONU to the next:** the ONU page has *Previous* and *Next* (in list order, on to the next OLT at the
  end of one) and a link back to *All ONUs*.
- **The top search (Ctrl K)** finds ONUs by name or serial on every OLT, and OLTs and routers by name or address,
  next to clients and invoices.
- **Overview:** the ONU figures, the OLTs table and "See them" open the list of all ONUs with the right filter.
- The menu's "OLT and ONU" is now two items: **ONUs** and **OLTs**.

## What the update changes on the server

Nothing besides the code. Customers stay connected.
