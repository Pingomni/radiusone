# RadiusOne 2.26.0

The OLT page in the new look, same layout. Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

- **The four figures in one strip:** ONUs online, offline, weak signal and uplinks. Offline and weak signal open the
  matching ONUs.
- **The OLT's state as a dot and a word** (Healthy, Needs a look, Problem), and its name as the page title.
- **PON ports in use:** the online count and the average signal, with the port's state as a bar along the bottom.
- **A shorter line under the OLT:** when the ONUs and the MAC table were read, Client mapping and the MAC export.
- The cards and their port lights, the tabs and the ONU list stay as they were.

## Fixed

- A key figure that needs action now (such as Overdue on Billing) was drawn as a red block instead of a red number.

## What the update changes on the server

Nothing besides the code. Customers stay connected.
