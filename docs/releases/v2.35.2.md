# RadiusOne 2.35.2

Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

- **Fixed:** an ONU can be weak because of the signal the OLT receives from it, while the signal at the ONU is
  good. The list showed such an ONU with a green bar and the OLT value in grey, so it looked fine. Now the
  "OLT −30.5" line is amber or red by its own level, and the bar has a second, thinner mark for the OLT's reading.
  Hovering shows both readings in words. Same on the client side panel and the client's ONU tab.

## What the update changes on the server

Nothing besides the code. Customers stay connected.
