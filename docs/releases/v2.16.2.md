# RadiusOne 2.16.2

The ONU's page opens faster. Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

- **The ONU's page took about 14 seconds to show what the ONU has now.** It now takes about half of that, and when the ONU
  was looked at in the last 5 minutes, the page shows that read at once and brings it up to date straight after.
- **Every read of an OLT over telnet is faster.** The portal now tells the OLT, for its own login only, to stop asking
  "press Enter for more options" after each command. The MAC table, the inventory and the configuration copy gain from it too.
- **The page no longer asks the OLT to measure the ONU's traffic at that moment.** The OLT takes over 4 seconds to do it,
  and the traffic graph on the same page already shows it.

## What the update changes on the server

Nothing besides the code. Nothing is changed on any OLT: the setting above lasts only as long as each login. Customers stay connected.
