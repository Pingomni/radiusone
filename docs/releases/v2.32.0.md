# RadiusOne 2.32.0

Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

- **Rogue ONU detection:** the OLT checks every PON port for a rogue ONU (one that sends light out of turn and can take
  every ONU on the port offline). RadiusOne reads this every 15 minutes with the port optics and now:
  - shows it on the Overview under *Needs attention*, with a link to the OLT's ports;
  - writes "Rogue ONU on the port" and "Rogue ONU cleared" in the OLT's changelog;
  - can send an admin alert: tick **OLT problem (rogue ONU, OLT cannot be read)** in
    *Settings → Notifications → Admin alerts*. The same check also alerts when an OLT cannot be read.
- The ports table on the OLT page already marked a rogue ONU in red; that stays.

## What the update changes on the server

Nothing besides the code. Customers stay connected.
