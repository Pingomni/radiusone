# RadiusOne 2.34.0

Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

- **Print and Save for payment receipts:** **Print** opens the receipt in a new tab, ready to print; **Save PDF**
  downloads it. They are on:
  - the invoice page (once something is paid);
  - Online payments → a paid payment;
  - Billing → *Latest payments*, next to each payment;
  - the client's *Billing* tab, in the *Payments* table and the invoices' *Documents* column.

## What the update changes on the server

Nothing besides the code. Customers stay connected.
