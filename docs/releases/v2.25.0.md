# RadiusOne 2.25.0

A new client page. Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

- **The client's name is the page title,** with the username, status and contacts under it and Diagnostics and New
  invoice beside it.
- **Key figures in one strip:** service, expiry, balance and open invoices.
- **An Overview tab opens first:** data used (7 days, 30 days or 12 months) and the recent sessions.
- **The live account facts stay on the right,** without two rows that repeated others.
- **Fewer words:** shorter field hints and notices across the client's tabs.

## What the update changes on the server

Nothing besides the code. Customers stay connected.
