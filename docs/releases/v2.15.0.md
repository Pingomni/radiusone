# RadiusOne 2.15.0

Routing or bridging in one place, a mode for each Ethernet port, and speeds by their size. Update with
*Settings → Overview → Software update*, or `sudo radiusone-update`.

## ONU mode

- **Routing or Bridging,** on the ONU's **Configure** tab, with what the ONU has now. Routing sets its internet connection:
  DHCP, PPPoE or a fixed address.
- **Switch to bridging** takes off exactly the internet connection, route policy and LAN routing that the ONU's running
  configuration shows, then puts each LAN port's untagged traffic on the VLAN you choose. You see the commands first.
- **The forms start from the running configuration:** the connection number (ip-index), VLAN, priority, profiles and PPPoE
  username the ONU has, so a change replaces its connection instead of adding a second one.

## Ethernet ports

- **A mode for each LAN port:** LAN (routed through the ONU), Access (untagged on one VLAN), Trunk (tagged VLANs; with an
  untagged one too it is hybrid) or Transparent. Only what differs from the running configuration is sent, and what goes
  is taken off before what comes is added.

## Speeds

- **Speeds by their size:** 100M, 1G or Unlimited instead of traffic table numbers, in the list and when choosing.
- **Add a speed** creates a traffic table of that size on the OLT. A speed the OLT already has is refused.

## What to know

- **Checked against SmartOLT's configuration on a Huawei MA5800-X7:** the DHCP routing commands and the LAN port native
  VLAN are the same as SmartOLT sent to the ONUs of the same OLT.
- **Not yet run on a real OLT:** the commands that take a connection off (`undo ont ipconfig`, `undo ont internet-config`,
  `undo ont wan-config`, `undo ont policy-route-config`), the tagged and transparent port commands (`ont port vlan`), and
  adding a traffic table. If the OLT does not accept one, you see its error and nothing more is sent: check the ONU's
  running config, as the commands before it were done. Try them first on a spare ONU.
- **DHCP control on a LAN port** and management IP, TR-069 and VoIP are not here: they need TR-069 or ONU-specific settings.
- **As before,** every change needs *Allow changes from the portal*, checks the ONU's serial number first, and is written
  to the audit log with the commands sent.

## What the update changes on the server

Nothing in the database. No OLT is changed by the update. Customers stay connected.
