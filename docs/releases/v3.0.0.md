# RadiusOne 3.0.0

- Every server now registers with a free licence from the PingOmni account, RadiusOne Community included. Get it at [account.pingomni.com](https://account.pingomni.com/buy?product=radiusone&plan=Community&period=12) (RadiusOne Community: free, up to 150 clients, one key per server) and paste it under Settings → License. It turns no Pro feature on; a Pro key registers the server as well.
- After this update, a server without a key shows a banner on every page with the days left (30). Then the console shows only "Register this server", with a button to get the free key and a field to paste it; sign-in, two-step sign-in and Settings → License stay open, and the console opens again as soon as a key is saved.
- RADIUS, the network queue, scheduled jobs and the payment pages keep working with or without a key: subscribers are never affected.
- The free key renews itself each year in the account and the server picks it up by itself; an expired key is still accepted for 30 days, with a banner asking to renew it.
- Settings → License names a free key "Community (registered)". Keys from before this release keep working as they are.
