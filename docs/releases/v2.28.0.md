# RadiusOne 2.28.0

The rest of the portal in the new look. Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

- **Buttons beside the page title** on NAS devices, Services, Static IP pools, OLT and ONU and Monitoring; the rows of
  buttons under the title are gone, and so are "Back to" buttons the breadcrumb already covers.
- **Monitoring:** the last poll time sits under the title, with Poll now beside it.
- **A NAS's page** has its name as the title, its state as a dot and a word, and Live monitor beside it.
- **Plain titles** in sentence case ("NAS devices", "Service plans", "Routers"), and no title said twice in the
  breadcrumb.
- **Fewer words:** shorter notices on Reports, NAS devices, the OLT list and Network operations; the Reports notice only
  shows when some sessions look wrong.

## What the update changes on the server

Nothing besides the code. Customers stay connected.
