# RadiusOne 2.29.0

The last pages in the new look. Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

- **Sign in, two-step sign-in and confirming it's you:** one light card on the dark frame, the brand above it, and
  shorter words.
- **Buttons beside the title** on the OLT form, new ONUs, NAS monitor, RADIUS server, connection diagnostics and the
  invoice form; "Back" buttons the breadcrumb already covers are gone.
- **Shorter help texts** on the OLT form and page, new ONUs, static IP pools, notifications, licence, contract template,
  users and NAS diagnostics.
- **Plain titles:** My account, Service plan, Static IP pool.

The ONU page follows once the OLT page is approved.

## What the update changes on the server

Nothing besides the code. Customers stay connected.
