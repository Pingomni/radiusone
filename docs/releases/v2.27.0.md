# RadiusOne 2.27.0

Billing, contracts and online payments in the new look. Update with *Settings → Overview → Software update*, or
`sudo radiusone-update`.

- **Buttons beside the page title:** Export and New invoice, New contract, Export on payments.
- **Status views as tabs with counts,** like the client list.
- **Statuses as a dot and a word.** A part-paid invoice also shows how much is paid; a paid one shows nothing more.
- **Invoice rows:** Record payment while something is owed; the invoice number opens the invoice.
- **The invoice page:** plain labels, and the breadcrumb leads back to Billing.
- **Shorter notice** after a recurring billing run that needs a look.

## What the update changes on the server

Nothing besides the code. Customers stay connected.
