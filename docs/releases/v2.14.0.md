# RadiusOne 2.14.0

A new ONU page that reads like the device, a name you change in place, and the ONU's internet connection pushed over
OMCI. Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

## The ONU's page

- **At a glance.** The ONU's name, serial number, model and position, how long it has been online or offline, its fibre
  distance and today's disconnections. A drawing of the ONU lights each LAN port by its link.
- **Signal meters.** The ONU's and the OLT's received power as large numbers on a scale with the OLT's own weak and very
  weak levels marked, and the ONU's transmit power. Traffic right now beside them.
- **The last 24 hours.** One strip: online, offline, and hatched where there was no read, with the share of time online.
- **Location, Customer, Device and Service** cards, and tabs for Graphs, Ports, Speed profiles, Configure, Running config
  and Manage.

## Rename an ONU

- **The pencil next to the ONU's name** changes its description on the OLT, where it is shown.

## Configure over OMCI

- **Internet connection.** DHCP, PPPoE or a fixed address, on a VLAN of the OLT, with its priority, and optionally a WAN
  profile and a route policy profile. **Route all LAN ports through this connection** turns routing on for each LAN port.
- **PPPoE from RADIUS.** Choose the RADIUS login of the client linked to the ONU: the server reads the password itself,
  so it never passes through the browser. A typed username and password work too.
- **Commands the OLT will get** shows them before anything is sent.
- **LAN port VLANs.** Set the VLAN each LAN port puts untagged traffic on, for bridged ONUs. The OLT is read again to check it.

## What to know

- **Every value is checked before it reaches the OLT.** The VLAN and the profiles must exist on the OLT, addresses must be
  IPv4 and the gateway in the address's network, and a PPPoE login may hold no spaces, quotes or question marks.
- **A PPPoE password is never kept.** It shows as `******` in the audit log and in the OLT's error messages.
- **Connection number.** The connection is set as `ip-index 1`, as ONUs are added. To change a connection an ONU already
  has under another number, choose that number under **More**.
- **As before,** every change needs *Allow changes from the portal*, checks the ONU's serial number on the OLT first, and is
  written to the audit log with the commands sent.
- **Tested on a simulator.** The PPPoE and fixed-address commands were not yet run on a real OLT: if the OLT does not
  accept them, you see its error and nothing more is sent.

## What the update changes on the server

Nothing in the database. No OLT is changed by the update. Customers stay connected.
