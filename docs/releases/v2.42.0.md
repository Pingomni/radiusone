# RadiusOne 2.42.0

- OLT page, Ports tab: each uplink port has "Add description" or "Edit" in its Description column.
- The description is saved on the OLT itself and read back before the portal shows it. Saving an empty description removes it.
- Up to 64 characters: letters, digits, spaces and simple punctuation.
- It needs telnet and changes turned on for the OLT. Each change is in the OLT's changelog.
