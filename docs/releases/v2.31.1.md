# RadiusOne 2.31.1

Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

Design fixes from a check of every page (OLT pages not included).

- **Nothing cut off on a 1440 px screen:** the NAS list (vendor and description now sit under the IP and name), the
  client page tabs, the client Billing tab's invoice table, and the Settings tabs. Tab icons hide on narrower screens.
- **One status style everywhere:** the remaining small coloured pills ("enabled", "no recent update", "expired",
  SNMP "Not set up", roles, firewall and backup states, licence features) are now a dot and a word, like the rest.
  "Not set up" is grey instead of green.
- **Client account panel:** shows the plan's name instead of its RADIUS group, and the session rows only while the
  client is online, instead of a column of dashes.
- **Tables** no longer show a grey shade on their right edge when nothing scrolls.
- **Export buttons** are all called "Export CSV".
- **Invoice page:** its buttons sit beside the title.
- **RADIUS server page:** the figures are one strip like other pages; the "no temperature sensors" note appears once.
- **Billing on a phone:** the status filters stay on one scrolling row.
- **Fewer hint texts** on the service, static IP pool, NAS and client forms and the NAS monitor page.

## What the update changes on the server

Nothing besides the code. Customers stay connected.
