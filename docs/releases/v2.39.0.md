# RadiusOne 2.39.0

Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

- **A shorter Network menu:** *NAS devices* and *OLTs* are no longer separate menu items. They are tabs of
  **Devices**: *All* (every device with its state), *Routers* (the NAS list with its RADIUS settings), *OLTs* and
  *Needs a look*. The same tabs sit on all three pages, and the menu keeps Devices selected on any router or OLT
  page. Nothing was removed: every page and button is where it was, one click from Devices.
- One ONU's page now keeps **ONUs** selected in the menu.

## What the update changes on the server

Nothing besides the code. Customers stay connected.
