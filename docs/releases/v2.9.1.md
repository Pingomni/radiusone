# RadiusOne 2.9.1

A fix for 2.9.0. Update with *Settings → Overview → Software update*, or `sudo radiusone-update`.

- **Pages failed with "Application error" after updating to 2.9.0.** The portal's database account had no access to
  the two new tables (contracts and online payments), so every page that reads them failed: Settings, Billing, the
  client pages and Online payments. The update now grants it, and a test checks that every new table is granted.

## What the update changes on the server

Database permissions only. Customers stay connected; RADIUS was never affected.
